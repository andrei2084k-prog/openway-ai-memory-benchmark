# Kitefold 4.6 release notes

Released September 22, 2026

Release 4.6 is built around the Template Marketplace. It also includes a round of smaller improvements to the editor and publishing flow, and a set of fixes we collected from support conversations and our own testing. The details are below.

## New

**Template Marketplace v2.** The marketplace has been rebuilt from the ground up. Browsing, searching and filtering by category are faster, and each listing now has a cleaner page with a description, supported plans and a list of what the template includes.

**Preview in AR before you buy.** Since release 4.6, a marketplace template can be previewed in AR before it is bought. Open a listing, choose Preview, and scan the code with your phone. The template runs in your camera view so you can judge scale, placement and motion in your own space. Nothing is added to your workspace until you buy.

**New revenue share for partners.** With Template Marketplace v2 (release 4.6, September 22, 2026), partners keep 70% of each sale and Kitefold keeps 30%. Each partner dashboard now shows sales for each template and the split on each sale, so the numbers are visible in one place.

**Clearer listing tools for partners.** Partners can now add several preview images to a listing, write a short changelog for each template version, and mark which plans a template is designed for.

## Improved

- **Faster template install.** Buying a template now places it in your workspace as an editable project, with its assets already linked, so you can start customizing at once.

- **Search that understands you.** Marketplace search matches on template names, categories and descriptions, and handles minor spelling mistakes.

- **Canvas selection.** Selecting overlapping objects in the Canvas 3D viewport is more predictable. Repeated clicks now cycle through the objects under the cursor in a consistent order.

- **Asset panel.** Large asset lists scroll more smoothly, and the panel remembers your sort order between sessions.

- **Publish checks.** The pre-publish check now explains in plain language why a warning appears and points to the setting that fixes it.

- **Preview codes.** The code shown for a marketplace preview refreshes automatically when it expires, so you no longer need to reopen the listing.

## Fixed

- Fixed a bug where undoing a transform after duplicating an object could move the original instead of the copy.

- Fixed a layout problem that cut off long project names in the project switcher.

- Fixed an issue where an image asset with transparency could show a faint halo in the camera view.

- Fixed a case where renaming a project folder did not update the breadcrumb until the page was reloaded.

- Fixed an error that appeared when opening the share dialog for a project with no published version.

- Fixed a problem where keyboard focus stayed in the asset search box after closing the panel.

- Fixed a rare issue where an animation preview could continue playing after you left the timeline.

## Notes for partners

If you already sell on the marketplace, your existing listings carry over to v2 automatically. Open your partner dashboard to review how each listing looks on the new page, add preview images, and confirm the plans each template supports. Questions about the revenue share can go to your partnerships contact.

## Questions

If something behaves differently from what these notes describe, tell the Kitefold Care desk and include the project name and a short description of what you saw. We read every report and use them to plan the next release.
