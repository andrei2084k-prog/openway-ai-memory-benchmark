# Kitefold 3.9 release notes

December 9, 2025

Release 3.9 shipped on December 9, 2025. This release is about keeping printed material useful for longer and getting your numbers out of Kitefold and into the tools you already use. There are two headline changes, a handful of improvements, and some fixes.

## New

### QR Launch: dynamic redirects

Since release 3.9, one printed QR Launch code can be redirected to a new experience without reprinting. Until now, a code was tied to the experience it was created for, so a seasonal campaign, a changed menu or a retired promotion meant a new print run. Now you keep the code on the packaging, poster or shelf talker, and point it somewhere else whenever you need to.

To change where a code leads, open the code in QR Launch, choose the experience you want it to open, and save. Visitors who scan the code afterward land on the new experience. The code itself does not change, so anything already printed keeps working.

### Pulse: CSV export of daily views

Pulse exports daily views to CSV since release 3.9. Open any experience in Pulse, pick the range you want to look at, and choose Export. You get one row per day, ready to open in a spreadsheet or load into your own reporting. Agencies can use it to build brand-partner reports without copying numbers by hand, and in-house teams can line up camera-experience views against campaign calendars.

## Improved

- **Editor responsiveness.** Panels in the editor open and close more smoothly when a scene contains many objects.

- **Clearer publish messages.** If an experience cannot be published, the message now says which item needs attention instead of showing a general error.

- **Asset library search.** Search now matches on partial names, so you can find a model or image without remembering its full file name.

- **Pulse date picker.** The range selector remembers your last choice when you move between experiences.

- **QR Launch list view.** Codes are easier to scan in the list, with the linked experience shown beside each one.

## Fixed

- Fixed an issue where an uploaded image could appear rotated in the editor preview, even though it was correct on the device.

- Fixed a case where the undo command in the editor skipped a step after you duplicated an object.

- Fixed a layout problem that cut off long experience names in the project list on narrow browser windows.

- Fixed a delay in the asset library where a newly uploaded file sometimes took longer than expected to show a thumbnail.

- Fixed a Pulse chart label that overlapped the axis when a range covered only a few days.

## Notes on upgrading

You do not need to install anything. Release 3.9 is already live for every workspace, and the new QR Launch and Pulse options appear in your existing projects. If you have questions about redirecting a code or setting up a report, the Kitefold Care desk is glad to help, and we read all the feedback you send.
